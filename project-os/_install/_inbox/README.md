# _inbox/

Drop existing documents here to prefill the OS — the brief, an SOW or contract, a kickoff deck, a proposal, meeting notes, an org chart.

During `/onboard` (or any session), the agent reads what's here, extracts the project's context, and files each fact into the right folder (`context/`, `admin/`, `decisions/`, `meetings/`). Once a document has been absorbed, its original is **moved** into the folder it informed (or into `_inbox/archive/`) — so this stays an inbox, not a graveyard. Nothing here is deleted unless you explicitly ask for it; your dropped file may be the only copy.

You never have to format anything. Just drop it here and say "set me up" (or run `/onboard`).
