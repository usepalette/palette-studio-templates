# design/

Design rationale, links to design tools, and written context that doesn't live in the design files themselves.

## What lives here

- [`design-links.md`](./design-links.md) — index of Figma files, prototypes, and other design URLs
- Written design rationale (e.g. `why-we-chose-this-flow.md`)
- Exported snapshots if you need them in the repo (use sparingly — the design tool is the source of truth)

## What does *not* live here

- The actual design files — those live in Figma (or your design tool)
- Design decisions with project-wide consequences → [`../decisions/`](../decisions/)
- User research that informed the design → [`../research/`](../research/)
