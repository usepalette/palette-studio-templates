# context/

The "what and why" of the project. A new person should be able to read this folder and understand the engagement.

## What lives here

- [`project.md`](./project.md) — project metadata (client, phase, dates, leads, recent activity) — powers the `overview.html` dashboard
- [`brief.md`](./brief.md) — the project brief: problem, audience, success criteria
- [`stakeholders.md`](./stakeholders.md) — who's involved on both sides (feeds the dashboard)
- [`goals.md`](./goals.md) — outcomes, non-goals, success metrics (feeds the dashboard)
- [`glossary.md`](./glossary.md) — terms and acronyms used in this project

## What does *not* live here

- Meeting notes → [`../meetings/`](../meetings/)
- Decisions → [`../decisions/`](../decisions/)
- Scope / timeline / billing → [`../admin/`](../admin/)
