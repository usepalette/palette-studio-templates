# meetings/

One file per meeting.

## Convention

- **Filename:** `YYYY-MM-DD-short-topic.md`, e.g. `2026-03-14-design-review.md`.
- **Template:** copy [`TEMPLATE.md`](./TEMPLATE.md) — or run `/new-meeting`, which dates, stamps, and indexes it for you.
- **One topic per file.** If two meetings happen in one day, use two files.

## Tips

- Capture **decisions** and **action items** clearly — they're the part people come back for.
- Promote anything decided here into [`../decisions/`](../decisions/) if it's load-bearing (`/new-decision`).
- Promote action items into your task tracker — this folder is the record, not the to-do list.
