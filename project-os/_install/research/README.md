# research/

User and market research that informs the project.

## What lives here

- [`interview-TEMPLATE.md`](./interview-TEMPLATE.md) — copy this for each user interview
- [`findings.md`](./findings.md) — running synthesis across all research
- Individual interview write-ups, named `YYYY-MM-DD-participant.md` (first name or a pseudonym)
- Market or competitor scans, surveys, analytics notes

## What does *not* live here

- Raw recordings — link to where they're stored, don't drop the file here
- Personally identifying data — anonymize before writing up
- Decisions made *because* of research → [`../decisions/`](../decisions/)
