# admin/

The business side of the engagement: scope, timeline, contracts, billing.

## What lives here

- [`scope.md`](./scope.md) — what is and isn't included
- [`timeline.md`](./timeline.md) — phases and key dates (feeds the dashboard)
- Contracts, SOWs, and amendments (link to the source of truth where possible)
- Billing notes — invoices, retainers, change orders

## What does *not* live here

- Day-to-day deliverable status → [`../deliverables/`](../deliverables/)
- Decisions on scope changes → [`../decisions/`](../decisions/) (and reference here)
- **Sensitive financial details** — keep in the appropriate system, link to it here
