# assets/

Static files for the workspace: the project or client logo, a hero image for the README, and any brand images the dashboard uses.

- `logo.svg` — optional. If present, `overview.html` shows it in the header; if absent, the dashboard falls back to a neutral wordmark, so it's safe to leave empty.
- Keep this light — link to large binaries (video, big design exports) rather than committing them.
