# Brand

Voice, messaging, and positioning — the reference every piece of external writing should be checked against.

## What goes here

| File | Purpose |
|---|---|
| `voice.md` | How [Company] sounds — tone, rhythm, what to avoid. Load before writing anything external. |
| `messaging.md` | Core messaging pillars — the claims we make and how we phrase them. |
| `positioning.md` | Where we sit in the market relative to alternatives. |

**Rule:** never write external copy from memory — load `voice.md` first, every time. Each file above exists as a **structured placeholder** — open it, follow the sections, and fill in the real thing during onboarding (or point an agent at existing brand docs via `_inbox/`).
