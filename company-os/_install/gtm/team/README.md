# Team

Individual GTM context — one folder per person.

## Structure

Each person gets a folder scaffolded from `_template/`:

```
team/
├── _template/
│   ├── README.md   ← GTM focus, what they own
│   └── voice.md    ← personal writing voice
└── <name>/
    ├── README.md
    └── voice.md
```

## What goes where

- **`README.md`** — current GTM focus, ownership areas, preferences. The quick-glance file.
- **`voice.md`** — how this person writes and communicates. Read this before writing anything as or for them; check it alongside the shared `../foundations/brand/voice.md`.

## When to add someone

Add a folder for anyone who regularly writes or is written for in GTM (founders, GTM hires, anyone with a public voice). Keep it lightweight — deep personal context belongs in that person's own space, not here.
