# ops — operating posture

`ops/` is [Company]'s operations space (finance, investors, legal, admin, hiring) inside [the company OS](../AGENTS.md). Company-wide rules live in the root `../AGENTS.md`; `README.md` is the map of what's here. **This file is the mindset for working in ops — read it before touching anything here.**

## How to work in ops

- **Treat everything here as sensitive and founders-only.** Finance, cap table, investor terms, legal, comp. Don't surface ops details in other spaces or external drafts unless explicitly asked. When in doubt, ask before sharing.
- **Nothing goes out without a founder's review.** Never auto-send investor updates, board material, or external legal/finance comms — draft it, then hand it to [Owner] (or the relevant founder) to send. Hard rule.
- **Numbers and legal terms must be exact.** Don't estimate or paraphrase figures, dates, ownership %, or contract terms — pull the real value from the source file, or say you need it. A wrong number here is worse than no number.
- **Investor/board-facing writing uses the founder's voice.** Warm, specific, honest; no "excited to share" openers, no corporate filler. The founder's full voice + comms rules live in `people/<name>/`, if written down — read it before drafting in their name.
- **Investor updates should follow a template + cadence**, once one exists. See `investors/README.md` for what's in place.

## Where things are

See `README.md` for the folder map. For the *latest* company/finance context (current numbers, round state), use the live connector — not stale files.
