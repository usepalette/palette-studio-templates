# Investors

Everything related to [Company]'s investors and fundraising communications.

## What goes here

- Round terms — current terms, internal floor vs public target
- Decks — pitch/investor decks and their narrative notes
- Updates — monthly investor update history + a template for new ones
- Per-investor context — one folder per investor or fund, with their terms and history
- Dataroom — a point-in-time package shared with investors, if one exists (it mirrors the live spaces; it is not the source of truth)

Don't invent numbers, terms, or documents here — this folder starts empty. Add real files as they exist, and list them above.
