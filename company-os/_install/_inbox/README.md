# Inbox — drop your existing stuff here

A staging area for setting up (and feeding) your OS. **Drop anything here that already describes your company** and let an agent file it:

- Pitch deck, one-pager, company overview
- An existing `CLAUDE.md` / `AGENTS.md` / team wiki
- Notion / Confluence / Google Docs exports
- Org chart, team list, CRM or pipeline export
- Meeting notes, call transcripts, screenshots

Then tell an agent:

> **"Set up my OS from the files in `_inbox/`."**

The agent reads everything here, extracts the useful context, writes it into the right spaces (`accounts/`, `gtm/`, `people/`, …) using the scaffolding commands, and then clears this folder. Nothing here is a source of truth — it's raw material on its way to a home.

**During normal use**, you can keep using `_inbox/` the same way: drop a doc you haven't filed yet, and ask an agent to put it where it belongs. Keep it empty when you can — an inbox is for processing, not storage.
