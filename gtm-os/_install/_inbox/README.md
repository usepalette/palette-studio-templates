# _inbox/

Drop existing docs here to prefill the OS — a pitch deck, a positioning doc, a brand guide, a team list, a CRM export.

During `/onboard` (or any session), the agent reads what's here, extracts your GTM context, and files each fact into the right folder (`foundations/`, `team/`, `accounts/`). Once a document is absorbed, its original is moved into the folder it informed or removed.

You never have to format anything. Just drop it here and say "set me up" (or run `/onboard`).
