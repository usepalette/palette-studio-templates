# Competitors

Capability-focused profiles of what alternatives actually ship.

## Rules

- One file per competitor, copied from `_template.md`.
- Separate current fact from inference and future signal.
- Cite docs, changelogs, demos, pricing pages, and other primary sources.
- Name where they are ahead. Competitive work exists to sharpen decisions, not flatter the team.
- If another folder or connected system is already the canonical competitor source, link to and
  use it instead of creating a second profile. Keep this folder canonical only when the team
  chooses it.
- Update the tracked list below when adding a profile.
