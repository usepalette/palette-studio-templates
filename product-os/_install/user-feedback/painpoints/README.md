# Painpoints

Synthesized problems supported by one or more sources. These describe the pain, not the requested
solution.

## Graduation rule

Create or update a painpoint when:

- The same underlying problem appears in at least two independent sources.
- A structured interview surfaces a clearly blocking problem. If this is the only source, say so.

Do not turn one casual complaint into a recurring pattern.

## File shape

[`_template.md`](_template.md) is the canonical shape. Copy it or run `/synthesize-feedback`; do
not recreate the schema from memory.

Use `/synthesize-feedback` so sources, scores, and company profiles stay aligned.
