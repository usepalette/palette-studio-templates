# Feedback recaps

Sourced summaries prepared for sharing with a team, customer, or stakeholder.

Create these only when the user asks to save a `/share-feedback` draft. Name them
`YYYY-MM-DD-company-or-topic.md`.

Every recap carries `source_files` linking the exact feedback, interviews, requests, and
painpoints it summarizes. A recap is a communication artifact, not a new source of product
evidence.
