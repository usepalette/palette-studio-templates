# Team

Optional profiles for people involved in product work: role, ownership, communication
preferences, and durable corrections. A solo user does not need to create a profile unless it
helps future agents work with them.

Use `/new-person` to create `team/<name>/` from `_template/`. Each profile contains:

- `README.md` - stable role, ownership, and working preferences.
- `lessons.md` - what to do differently when working with that person.
- `log.md` - notable history specific to that person.

Current priorities and roadmap opinions belong in `../team-input/`, not in the stable profile.
