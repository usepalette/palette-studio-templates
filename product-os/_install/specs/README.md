# Specs

Paste-ready briefs for one buildable piece of work.

Product OS keeps the draft and its evidence. When the team uses an issue tracker, it remains the
source of truth for ownership, status, delivery, and the roadmap.

## Rules

- Start from `_template.md` or run `/spec`.
- Name the file for what ships, using kebab-case.
- Link the painpoint, discovery result, strategy thesis, or other evidence that justifies the work.
- Keep it tight. If a section becomes a research essay, move that material upstream.
- When the team uses a tracker and the spec is there, add its link to the file.
