# Inbox

Temporary landing zone for material that can help set up or backfill Product OS: research exports,
interview notes, feedback dumps, strategy documents, old specs, or roadmap briefs.

An agent should read each item, propose where its durable content belongs, confirm the mapping, and
then move or remove the original. Only place material here when the workspace audience is allowed
to see it. Prefer links for bulk or restricted exports, and do not let this become permanent
storage.
