# Commands

| Command | Purpose |
|---|---|
| `/onboard` | Set up Product OS from live context, documents, or a short conversation |
| `/feedback` | Capture raw feedback and explicit asks |
| `/synthesize-feedback` | Find repeated patterns and maintain painpoints |
| `/feedback-sync` | Rebuild the feedback dashboard |
| `/share-feedback` | Draft a sourced recap and optionally send it after approval |
| `/spec` | Draft and save a paste-ready product spec |
| `/new-person` | Add a product teammate |
| `/review` | Check evidence, traceability, hygiene, and completeness |
| `/finish-session` | Capture decisions, follow-ups, and durable learning |
| `/workspace-heal` | Audit structural health and setup drift |
