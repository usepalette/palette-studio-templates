# Discovery

Open questions with a learning plan. Discovery sits between interesting signal and a justified
strategy thesis or spec.

Create a discovery file when the question is important but the answer is not yet known. Do not use
this folder for clearly scoped feature requests or meeting notes.

## Lifecycle

- `open` - worth exploring.
- `in-flight` - actively being researched.
- `promoted` - became a spec or strategy thesis; link the outcome.
- `closed` - answered without further action; record why.

Start from `_template.md`.
