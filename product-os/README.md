# Product OS

Your product work as a file system: one folder of markdown for user signal, discovery, strategy,
specs, competitors, and team input.

Built for product work from a solo builder to a cross-functional team. Different supported
agents can work from the same product evidence, decisions, and strategy while projects stay
in the issue tracker.

## What you get

- **A product evidence system.** Raw feedback, interviews, explicit requests, recurring pain points,
  and company context stay linked instead of becoming a pile of quotes.
- **A path from signal to decision.** Discovery questions, strategy theses, and paste-ready specs
  each have a clear job and trace back to their sources.
- **A feedback dashboard.** A self-contained HTML viewer for filtering product signal by company,
  type, sentiment, and tag. Markdown remains the source of truth.
- **Works with different AI agents.** Shared instructions help Claude Code, Codex, Gemini,
  Mistral, and other supported agents follow the same product rules and evidence.
- **Four ways to bring in existing context.** Start from Palette's Context Library, product
  documents in `_inbox/`, exports from other AI tools, or one short conversation.
- **Built-in workflows for recurring work.** Capture feedback, find repeated patterns, draft
  specs, review the evidence, and keep the workspace healthy.
- **Lessons and product history.** `lessons.md` captures what to do differently, `log.md` records
  what happened, and `log/sessions/` keeps the fuller recaps worth revisiting.

## How setup works

Product OS starts as a blank folder structure. Say **"set me up"** and start with the product material
you already use:

- Use connected context such as Palette's Context Library.
- Drop product briefs, research exports, feedback folders, or strategy documents into `_inbox/`.
- Use the built-in prompt to bring useful context over from ChatGPT, Claude, Notion, or another
  tool.
- Answer one short round of questions about the product, users, team, and feedback sources.

Setup works for a solo builder, product area, platform, or portfolio. A formal product owner,
team roster, issue tracker, analytics tool, and existing feedback are optional. The agent records
what is not used instead of inventing it, and confirms any folder changes before writing.

The agent sorts the material, preserves source links, and confirms any gaps before it writes.
Palette Desktop creates a checkpoint first, so you can undo.

## Work from the same product context

Open the folder with Claude Code, Codex, Gemini, or another supported agent. Each one can use
the same feedback, discovery, strategy, specs, and team input.

- "What are customers repeatedly saying about onboarding, and what evidence supports it?"
- "Draft a product spec grounded in our feedback, discovery, and strategy."
- "Help me bring our product brief, research, and feedback into this workspace."

Everything is plain markdown you can read and edit, with or without Palette.
